# 🔍 محرك بحث داخل الملفات

تطبيق ويب يتيح لك رفع ملف **PDF**، أو **صورة**، أو **Word (docx)**، أو **Excel (xlsx/csv)**، أو **أرشيف مضغوط (zip)** يحتوي على مجموعة من هذه الملفات، ثم يبحث في **محتوى** هذه الملفات (وليس فقط أسمائها) عن أي عبارة تكتبها، ويعرض لك مكان العبارة داخل كل ملف مع إمكانية **نسخها** بضغطة زر.

## المزايا

- 📄 **PDF** — استخراج النص من كل صفحة. الصفحات **الممسوحة ضوئيًا** (بلا طبقة نص، كملف مصوَّر أو فاكس) تُعالَج تلقائيًا عبر **OCR** بنفس تقنية الصور — لا حاجة لأي إعداد إضافي.
- 🖼️ **الصور** (JPG/PNG/WebP/…) — عبر تقنية **OCR** (تعرّف ضوئي على الحروف) تدعم العربية والإنجليزية معًا.
- 📝 **Word** (.docx) — استخراج نص المستند كاملاً.
- 📊 **Excel** (.xlsx / .xls / .csv) — استخراج محتوى كل ورقة عمل.
- 🗜️ **أرشيف مضغوط (.zip)** — يُفكّ تلقائيًا (حتى لو كان يحتوي على أرشيفات متداخلة) ويُعالج كل ملف مدعوم بداخله.
- 🔎 بحث فوري يتجاوز التشكيل واختلاف صيغ الحروف العربية (مثلاً البحث بـ **"مدفوعه"** يجد **"مدفوعة"**، والبحث بـ **"الايجار"** يجد **"الإيجار"**)، وغير حساس لحالة الأحرف بالإنجليزية.
- ✨ تمييز العبارة المطابقة داخل مقطع نصي (سياق) من الملف.
- 👁️ زر **"عرض"** على كل نتيجة من PDF أو صورة: يفتح الصفحة الأصلية (أو الصورة) مع تمييز مكان العبارة فيها بصريًا، لا مجرد نص مقتطع.
- 📋 نسخ أي نتيجة، أو كل نتائج ملف معيّن، أو كل النتائج دفعة واحدة، بضغطة زر.
- 🔒 **خصوصية كاملة**: كل المعالجة (قراءة PDF، فك الأرشيف، OCR، …) تتم داخل متصفحك عبر JavaScript/WebAssembly — لا يتم رفع أي ملف إلى أي خادم إطلاقًا.

## نسخة ملف HTML واحد (بدون نشر)

`standalone/file-search.html` نفس الأداة تمامًا، لكن معبّأة في **ملف HTML واحد مستقل** — نزّله وافتحه مباشرة بأي متصفح (بالنقر المزدوج) دون الحاجة لأي استضافة أو أوامر تثبيت. مكتبات معالجة **PDF وWord وExcel والأرشيف المضغوط** مُضمَّنة داخل الملف نفسه (base64) — تعمل هذه الصيغ حتى بلا إنترنت إطلاقًا. فقط ميزة **OCR للصور** تحمّل محرّكها (multi-MB) من الإنترنت عند أول استخدام لصورة، لأنه كبير جدًا ليُضمَّن في ملف واحد. ملفاتك بكل الأحوال تُعالَج محليًا فقط ولا تُرفع لأي مكان.

يُبنى `file-search.html` من `file-search.template.html` عبر `node standalone/build.mjs` (بعد `npm install` في جذر المشروع)، الذي يُضمِّن نسخ المكتبات المثبّتة فعليًا من `node_modules` — شغّله من جديد بعد تحديث أي من هذه الحزم في `client/package.json`.

## البنية

```
client/   واجهة React + TypeScript + Tailwind (Vite) — تطبيق ويب مستقل بالكامل (Static SPA)
```

لا يوجد خادم خلفي (Backend) ولا مفاتيح API مطلوبة؛ كل الاستخراج والبحث يعملان محليًا في المتصفح باستخدام:

| الصيغة | المكتبة |
|---|---|
| PDF | `pdfjs-dist` |
| Word (docx) | `mammoth` |
| Excel/CSV | `xlsx` (SheetJS) |
| صور (OCR) | `tesseract.js` |
| أرشيف مضغوط | `jszip` |

> ملاحظة: تحميل محرك التعرف الضوئي (OCR) وبيانات اللغة يتم من شبكة توصيل محتوى (CDN) في أول استخدام لصورة (ثم يُخزَّن مؤقتًا في المتصفح)، لذا يحتاج هذا الجزء تحديدًا اتصالاً بالإنترنت — أما محتوى صورك نفسه فلا يُرسل لأي مكان.

## التشغيل محليًا

```bash
npm install
npm run dev
```

الواجهة تعمل على: http://localhost:5173

## البناء للنشر

```bash
npm run build
```

الناتج في `client/dist` — مجلد ملفات ثابتة (Static) يمكن نشره على أي استضافة (Vercel / Netlify / Cloudflare Pages / GitHub Pages).

## النشر على Vercel — بدون سطر أوامر

1. أنشئ حسابًا مجانيًا على https://vercel.com (سجّل الدخول بحساب GitHub).
2. من لوحة Vercel: **Add New → Project**، واربط مستودع `boshaheen/-`.
3. عند شاشة الإعداد اترك **Root Directory** كما هو (جذر المستودع) — Vercel يقرأ إعدادات البناء تلقائيًا من `vercel.json`.
4. اضغط **Deploy**. لا حاجة لإضافة أي متغيرات بيئة (Environment Variables) — التطبيق بالكامل ثابت (Static) ولا يتصل بأي خادم خاص بك.
5. لأي تحديث لاحق: ادفع (push) تغييراتك إلى نفس الفرع على GitHub، وVercel يعيد النشر تلقائيًا.

## حدود معروفة

- صيغة Word القديمة `.doc` غير مدعومة، فقط `.docx`.
- دقّة التعرف الضوئي (OCR) على الصور تعتمد على وضوح الصورة وجودة التصوير.
- الملفات الكبيرة جدًا (خصوصًا PDF بمئات الصفحات أو صور عالية الدقة) قد تستغرق وقتًا أطول لأن كل المعالجة تتم على جهازك، وهذا هو الثمن مقابل عدم رفع ملفاتك لأي خادم.
