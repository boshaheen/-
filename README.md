# 🐫 مُقيّم الإبل الذكي

تطبيق ويب يستخدم الذكاء الاصطناعي (Claude Vision) لتقييم مستوى وجمال الإبل عبر:

- 📷 **تصوير مباشر** بالكاميرا (متصفح الجوال أو الحاسوب)
- 🖼️ **رفع صورة** موجودة مسبقًا
- تحليل **علامات الجمال** (الرأس، الرقبة، الأذنان، المشافر، السنام، الهيكل العام، القوائم، الوبر) وإعطاء درجة إجمالية من 100 ومستوى (ممتاز / جيد جدًا / جيد / متوسط / ضعيف)
- 📄 تصدير التقرير **PDF**
- 📤 مشاركة عبر **واتساب**
- ✉️ إرسال التقرير عبر **البريد الإلكتروني**
- 🗂️ سجل محلي لآخر التقييمات

بُني كتطبيق ويب متجاوب (يعمل من متصفح الجوال والحاسوب) بحيث يسهل لاحقًا تحويله إلى تطبيق جوال أصلي (React Native) لأن منطق الأعمال (`lib/`, `types.ts`) منفصل عن واجهة العرض.

## البنية

```
client/   واجهة React + TypeScript + Tailwind (Vite)
server/   خادم Express + TypeScript، يتصل بـ Anthropic API و Resend
```

## المتطلبات

- Node.js 20+
- مفتاح **Anthropic API** (لتحليل الصور بالذكاء الاصطناعي) — من https://console.anthropic.com
- (اختياري) مفتاح **Resend API** لإرسال التقارير بالبريد الإلكتروني — من https://resend.com

## التشغيل محليًا

```bash
# 1. تثبيت الحزم (من جذر المشروع، يثبت client و server معًا)
npm install

# 2. إعداد متغيرات البيئة للخادم
cp server/.env.example server/.env
# ثم افتح server/.env وأضف ANTHROPIC_API_KEY (وRESEND_API_KEY إن أردت تفعيل البريد)

# 3. تشغيل الخادم والواجهة معًا
npm run dev
```

- الواجهة: http://localhost:5173
- الخادم: http://localhost:8787 (يتم استدعاؤه تلقائيًا عبر `/api` من الواجهة أثناء التطوير)

افتح الرابط من متصفح جوالك (على نفس الشبكة) لتجربة الكاميرا مباشرة، أو استخدم متصفح الحاسوب.

> ملاحظة: بعض المتصفحات تتطلب **HTTPS** لتفعيل الكاميرا (`getUserMedia`) عند الوصول من جهاز آخر غير `localhost`. عند النشر الفعلي استخدم استضافة تدعم HTTPS تلقائيًا (Vercel/Netlify للواجهة).

## البناء للإنتاج

```bash
npm run build
```

- `client/dist` — ملفات الواجهة الثابتة (يمكن نشرها على Vercel / Netlify / Cloudflare Pages)
- `server/dist` — كود الخادم (يمكن نشره على Render / Railway / Fly.io / أي خادم Node)

عند النشر، اضبط متغيرات البيئة في منصة الاستضافة (`ANTHROPIC_API_KEY`, `RESEND_API_KEY`, `EMAIL_FROM`, `CORS_ORIGIN`) واجعل الواجهة تستدعي رابط الخادم الفعلي بدلاً من `/api` (عبر إعداد proxy أو متغير `VITE_API_BASE` إذا احتجت تعديل ذلك).

## كيف يعمل التحليل بالذكاء الاصطناعي

- الصورة تُرسل من المتصفح إلى `POST /api/analyze` على الخادم (وليس مباشرة إلى Anthropic) حتى لا يتم كشف مفتاح API في المتصفح.
- الخادم يرسل الصورة إلى نموذج Claude مع تعليمات دور "حكم مزايين إبل"، ويطلب تقييمًا منظّمًا (JSON) عبر آلية Tool Use لضمان دقة وثبات التنسيق.
- يحسب الخادم الدرجة الإجمالية من مجموع درجات الصفات الثمانية مرجّحة بأوزانها الثابتة، ثم يحدد المستوى النهائي.

## تنبيه

التقييم استرشادي ويعتمد على نموذج ذكاء اصطناعي عام (وليس نموذجًا مُدرَّبًا خصيصًا على بيانات مزايين الإبل)، وهو لا يغني عن رأي خبراء المزايين المعتمدين في المسابقات الرسمية.
