# 📄 قارئ PDF المحلي

موقع بسيط يعمل بالكامل على جهازك، بدون إنترنت وبدون أي خادم خارجي — مناسب للملفات والأوراق السرّية التي لا يجب أن تغادر جهازك.

## المزايا

- 📂 **رفع عدة ملفات PDF** بالسحب والإفلات أو باختيارها من الجهاز.
- 🔍 **بحث في محتوى الملفات** (نص عربي وإنجليزي) — يعرض النتائج مع اسم الملف ورقم الصفحة ومقتطف النص، وبالضغط على النتيجة يُفتح الملف مباشرة عند تلك الصفحة.
- 🗜️ **ضغط الملفات المختارة في أرشيف ZIP واحد** وتنزيله.
- ⚠️ **كشف الملفات "المزيّفة"**: يتحقق أولًا من أن الملف PDF فعليًا (وليس صورة أو ملفًا آخر أُعيدت تسميته بامتداد .pdf فقط)، ثم يحلل كل صفحة — فإن كانت الصفحات شبه خالية من النص (كحال المستندات الممسوحة ضوئيًا كصور) يُعلَّم الملف بوضوح كـ"صورة ممسوحة ضوئيًا، غير قابل للبحث" بدلًا من معاملته كملف نصي عادي.
- 🔒 **خصوصية كاملة**: لا يوجد أي كود في هذا المشروع يرفع الملفات إلى خادم أو يتصل بالإنترنت. كل التحليل والبحث والضغط يتم داخل متصفحك عبر JavaScript فقط.

## كيف يعمل

المشروع مبني بـ HTML/CSS/JavaScript عادي (بدون إطار عمل ولا خطوة بناء)، ويستخدم مكتبتين مجانيتين ومفتوحتي المصدر تم تحميلهما مسبقًا داخل مجلد `vendor/` (وليس عبر الإنترنت أو CDN):

- [`pdf.js`](https://mozilla.github.io/pdf.js/) من موزيلا — لقراءة ملفات PDF واستخراج النص منها داخل المتصفح.
- [`JSZip`](https://stuk.github.io/jszip/) — لإنشاء أرشيفات ZIP داخل المتصفح.

## التشغيل

هناك طريقتان لتشغيل الموقع، وكلتاهما محليتان بالكامل ولا تحتاجان إنترنت:

### الطريقة الأولى (الأسهل): ملف HTML واحد

افتح ملف [`pdf-reader-local.html`](./pdf-reader-local.html) مباشرة بالنقر المزدوج عليه في متصفحك (Chrome أو Edge أو Firefox) — لا حاجة لتثبيت أي شيء ولا تشغيل أي خادم. الملف يحتوي كل الكود والمكتبات (`pdf.js` و`JSZip`) مضمَّنة بداخله، فيعمل حتى وأنت غير متصل بالإنترنت إطلاقًا.

> إذا عدّلت `index.html` أو `css/style.css` أو `js/app.js`، أعِد بناء الملف الموحّد بالأمر: `node build-single-file.mjs` (أو `npm run build:single`).

### الطريقة الثانية: عبر خادم محلي بسيط

بعض المتصفحات تمنع تحميل بعض ملفات JavaScript (كملف pdf.js worker) عند فتح `index.html` مباشرة بطريقة `file://‎` بدل ملف HTML الموحّد أعلاه. لتشغيل نسخة الملفات المتعددة (`index.html`) استخدم الخادم المحلي المُرفَق داخل المشروع، ولا يحتاج أي تثبيت:

```bash
cd pdf-reader
node server.js
```

ثم افتح المتصفح على:

```
http://127.0.0.1:5500
```

الخادم يعمل على `127.0.0.1` فقط (وليس على الشبكة)، أي أن أي جهاز آخر على نفس الشبكة **لا يستطيع** الوصول إليه — يبقى الموقع خاصًا بجهازك فقط. لإيقاف الخادم اضغط `Ctrl+C`.

> بديل: يمكن استخدام أي خادم ثابت آخر لديك مسبقًا (مثل `python3 -m http.server 5500` من داخل مجلد `pdf-reader`)، النتيجة نفسها.

## بنية المشروع

```
pdf-reader/
├── pdf-reader-local.html   ملف HTML واحد مستقل يضمّن كل شيء — افتحه مباشرة بلا خادم (الطريقة الموصى بها)
├── index.html              الصفحة الرئيسية (نسخة الملفات المتعددة، تحتاج خادم محلي)
├── css/style.css           التنسيق
├── js/app.js               كل منطق القراءة/البحث/الضغط (بدون أي اتصال شبكي)
├── vendor/                 نسخ محلية من pdf.js و JSZip (لا تحميل من الإنترنت أثناء الاستخدام)
├── server.js               خادم ثابت محلي بسيط (Node.js، بدون أي حزم خارجية)
└── build-single-file.mjs   يُعيد بناء pdf-reader-local.html من الملفات أعلاه
```

## ملاحظات

- الملفات المصنّفة "صورة ممسوحة ضوئيًا" هي ملفات PDF حقيقية لكنها بلا طبقة نص (غالبًا نتيجة مسح ضوئي أو تصوير)، لذلك لا يمكن البحث داخل محتواها نصيًا. لجعلها قابلة للبحث يلزم تمرير عملية OCR (تحويل الصورة إلى نص) عليها أولًا — ميزة يمكن إضافتها لاحقًا كخطوة اختيارية منفصلة إذا احتجتها.
- عند حذف الصفحة أو إغلاق المتصفح تُفرَّغ كل الملفات من الذاكرة تلقائيًا؛ المشروع لا يحفظ أي شيء بشكل دائم على القرص.
